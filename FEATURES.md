# Story Engine — Complete Build

## Included
- Full converter + editor + player
- PPTX import with theme colors, interactive clicks, sounds
- **Fixed entrance animation extraction** (clickEffect, presetID e.g. 42 Float Up)
- Animation timeline, custom presets, click actions UI
- Dark/light theme, aspect ratios, auto-fit zoom
- JSON import/export, responsive drawers

## Run
```bash
npm install
npm run dev
```

## Key file
`src/story-engine/importers/pptx.ts` — PPTX + animation extraction
